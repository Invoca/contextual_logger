# Reflection Customizations

Project-specific overrides to the reflection agent's default behavior. **Empty by default** — the reflection agent uses its role definition as-is; this file adds nothing until you add rules below. To author customizations, see the ADLC framework README, "Customizing Agents".

Typical additions: this repo's own additional protected invariants, a stricter filing budget than the default, or repo-specific guidance on what counts as local rather than framework-level friction.
